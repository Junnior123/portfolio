
Animated one-page portfolio starter built with React, TypeScript, and Vite. Includes scroll reveals, cursor-reactive lighting, project cards, contact links, and light/dark themes.

## Get started

Requirements: Node.js 22+ and pnpm.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

## Customize

Edit project names, descriptions, tags, and links in `src/App.tsx`. Replace the sample email `hello@example.com` and Discord username `your_discord_username`. Update the page title and metadata in `index.html`.

## Build

```sh
pnpm build
pnpm preview
```

The static output is written to `dist/`.
